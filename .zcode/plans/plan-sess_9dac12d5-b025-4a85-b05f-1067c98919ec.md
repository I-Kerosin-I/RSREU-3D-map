# UI: tooltip аудиторий, хранилище объектов и панель поиска/категорий

## Context

Приложение (libGDX 1.12.1 + gdx-gltf, Maven: domain → application → core → desktop) рендерит 3D-модель главного корпуса с ray-picking по 75 хитбоксам (`main_room_*_hitbox`), но не показывает пользователю, *что* это за аудитории. Нужно:

1. **Tooltip при наведении** на хитбокс — название + описание (например «а.210, лаборатория кафедры ЭВМ»).
2. **JSON-хранилище** объектов карты: название, описание, категория, этаж, ссылка на хитбокс.
3. **Статическая боковая панель**: строка поиска (по названию и описанию) + дерево категорий с подкатегориями (кафедры → ЭВМ/САПР ВС/КТ…, WC → М/Ж, столовые, кофе-автоматы, лаунж-зоны, памятники, открытые аудитории, амфитеатры).

База уже заложена в проекте: `UI_ARCHITECTURE.md` предписывает Scene2D + Stage, централизованные стили, UI → контроллер → состояние; `MANIFEST_SCHEMA.md` + `ManifestLoader/Parser` + порт `CampusRepository` + `FindRoomsUseCase` уже существуют, но не подключены к `MapGame`, а `manifest.json` содержит тестовые данные. Принятые решения (варианты по умолчанию): хранилище = расширение `manifest.json`; таксономия категорий — в JSON (новая категория = правка JSON без Java); выбор объекта = блокировка этажа + подсветка + плавный перелёт камеры; манифест заполняется для всех 75 комнат (имена «а.XXX», категории/описания — где известны).

## Изменения

### 1. Данные — `assets/manifest.json` + `MANIFEST_SCHEMA.md`
- `model` → `models/MainCampus.glb`; этажи `floor1`–`floor4` (id `"1"`–`"4"`); space-записи для **всех** хитбоксов GLB (точный список извлечь скриптом из JSON-чанка GLB во временной папке).
- Каждому space: `id` (room id без `_hitbox`), `name` («а.210»), опц. `description`, опц. `category`/`subcategory`, `type` (ROOM/RESTROOM/...), `modelNode` = **полное имя хитбокса** (`main_room_210_hitbox` — однозначный join с выводом `RoomPicker`).
- Новая верхнеуровневая секция `categories`: `[{id, name, subcategories: [{id, name}]}]` — кафедры (подкатегории ЭВМ, САПР ВС, КТ, ФВТ), wc (М, Ж), canteen, coffee, lounge, monument, open_room, amphitheater. Категории проставить где известны: `main_room_WC_m*` → wc/М, `WC_f*` → wc/Ж, `buffet` → canteen, а.210 → departments/ЭВМ, а.324 → amphitheater (по примерам пользователя); остальные — без категории (доступны через поиск, в дереве появятся по мере заполнения JSON).
- Обновить `MANIFEST_SCHEMA.md`: spaces вложены в записи этажей (как парсит `ManifestParser` и текущий файл), `modelNode` = имя хитбокс-узла, новые поля, секция categories.

### 2. Domain — `domain/.../campus/`
- `Space.java`: добавить nullable-поля `description`, `category`, `subcategory` (+ компактный доп. конструктор); обновить call-site (`ManifestParser`).
- Новый record `CategoryTaxonomy(List<CategoryDef>)` + `CategoryDef(id, name, List<SubcategoryDef>)` (plain Java, libGDX-free).

### 3. Application — `application/.../usecase/FindRoomsUseCase.java`
- Поиск по `displayName` **и** `description` (case-insensitive contains); добавить `findByCategory(category, subcategory|null)`.

### 4. Core — репозиторий и контент
- Новый `core/content/InMemoryCampusRepository.java`: реализует `CampusRepository`, индекс `Map<String, Space>` по `modelNodeName` (O(1) на hover).
- `core/content/ManifestParser.java`: парсинг `description/category/subcategory` и секции `categories` → `CategoryTaxonomy`.

### 5. Core — мост UI ↔ 3D
- `render/RoomHighlighter.java`: публичные геттеры `hoveredHitbox()`, `lockedFloor()`; новая команда `selectRoom(String hitboxNodeName)` — тот же код-путь, что клик по комнате (resetAll → selectFloor → lock → highlight).
- `input/RoomPicker.java`: геттер `boundsOf(String hitboxNodeName)` (мировой AABB из кэша).
- `input/CameraInputController.java`: `flyTo(Vector3 worldTarget)` — плавное перемещение орбитальной точки к центру комнаты (экспоненциальное приближение в `update()`, как zoom target) + `setKeyboardBlockedSupplier(BooleanSupplier)` — блокирует WASD, пока фокус в TextField (иначе камера будет ездить при наборе текста).

### 6. Core — контроллер (замена заглушек)
- `controller/MapUiState.java` → типизированный record: `List<Space> searchResults`, `String selectedRoomId`.
- `controller/MapController.java`: команды `search(query)`, `selectObject(Space)`, `clearSelection()`; подписка слушателей `onStateChanged`; `hoveredHitbox()` (Supplier, устанавливаемый MapGame); интерфейс `MapActions { focusRoom(hitboxNodeName); clearFocus(); }` — реализует MapGame (вызывает `roomHighlighter.selectRoom` + `cameraController.flyTo`), UI 3D-узлов не касается.

### 7. Core — UI (`core/ui/`, новые классы; пустые заглушки `MapScreen/FloorSelector/RoomSearchUi` удалить)
- `UiTheme.java`: Skin программно — BitmapFont через **gdx-freetype** (шрифт `assets/fonts/PTSans-Regular.ttf`, OFL, кириллица; явно указать набор символов: DEFAULT_CHARS + русский алфавит), стили Label/TextField/Tree/ScrollPane/List, центральные цвета; `dispose()`.
- `MapHud.java`: владелец `Stage` (ScreenViewport); корневой Table; compose-панелей; `actAndDraw(delta)`, `resize()`, `dispose()`; подписка на MapController; опрос hover для tooltip; скрытие tooltip над UI (`stage.hit`).
- `SearchBar.java`: TextField «Поиск…» → `controller.search()` на каждое изменение (≤75 записей — без debounce).
- `SearchResultsPanel.java`: временный список результатов под строкой (лимит ~20), клик → `selectObject`.
- `ObjectBrowserPanel.java`: `scene2d.ui.Tree` из `CategoryTaxonomy` — категория → подкатегория → объекты; клик по листу → `selectObject`. Панель справа, ScrollPane.
- `RoomTooltip.java`: панель (фон — скруглённый Pixmap drawable) с названием + описанием (wrap); следует за курсором со смещением, clamp в границы экрана; показывается только для хитбоксов с данными в манифесте.

### 8. Зависимости (gdx-freetype — официальное расширение libGDX; стек текста с кириллицей не имеет)
- `pom.xml` (root): в dependencyManagement `gdx-freetype` + `gdx-freetype-platform:natives-desktop` с `${libgdx.version}`.
- `core/pom.xml`: gdx-freetype; `desktop/pom.xml`: gdx-freetype-platform natives-desktop.
- Скачать `PTSans-Regular.ttf` (google/fonts GitHub, OFL) в `assets/fonts/`; при недоступности сети — сообщить и подобрать системный шрифт с кириллицей.

### 9. Связка — `MapGame.java`
- `loadScene()`: сохранить `roomPicker`/`roomHighlighter` в поля.
- `create()`: загрузка манифеста → `InMemoryCampusRepository` → `FindRoomsUseCase` → `MapController` (+ реализация `MapActions`) → `UiTheme` → `MapHud`; ввод — `InputMultiplexer(stage, cameraController)` (Stage первым); сбой манифеста → лог + UI с пустыми данными.
- `render()`: после `sceneManager.render()` → `hud.actAndDraw(delta)`; `resize()` → `hud.resize()`; `dispose()` → `hud.dispose()`.
- Escape: `MapHud` снимает фокус с поиска, `CameraInputController` как прежде вызывает `clearSelection`.

## Не входит (осознанно)
Селектор этажей, подсветка *группы* по клику на категорию, world-space метки (§13 UI_ARCHITECTURE), локализация, Android-адаптация.
